# 導入

作業の前にプロジェクトをバックアップしてください。初めて使うときは、テスト用のプロジェクトで試すことをおすすめします。

1. BOOTHからダウンロードした `PDFReader-1.0.0.zip` を展開します。中には unitypackage、README.txt、説明書（Guides）、利用規約（Terms）が入っています。
2. VCCでワールドプロジェクトを作成します（既存のプロジェクトでもかまいません）。
3. `PDFReader-1.0.0.unitypackage` をインポートします。ファイルは `Assets/PDFReader` に入ります。
4. 初回の読み込み時、TextMesh Pro の Essential Resources がプロジェクトにない場合は自動でインポートされます。
5. Unityのメニューから **Tools > PDF Reader** を開きます。

動作確認には、付属のDemo PDF（`Assets/PDFReader/PDF/PDFReader-Original-Demo.pdf`）を使えます。次は [PDFを追加する](add-pdf.html) に進んでください。
