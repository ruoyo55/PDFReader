# Installation

Back up your project first. If this is your first time, try PDFReader in a test project.

1. Extract `PDFReader-1.0.0.zip` downloaded from BOOTH. It contains the unitypackage, README.txt, the guides (Guides) and the terms of use (Terms).
2. Create a world project with VCC (an existing project also works).
3. Import `PDFReader-1.0.0.unitypackage`. Everything goes into `Assets/PDFReader`.
4. On first load, TextMesh Pro's Essential Resources are imported automatically if the project does not have them.
5. Open **Tools > PDF Reader** from the Unity menu.

To try it out, use the bundled demo PDF (`Assets/PDFReader/PDF/PDFReader-Original-Demo.pdf`). Next: [Adding PDFs](add-pdf.html).
