# 安装

开始前请先备份项目。第一次使用时，建议先在测试用的项目中试用。

1. 解压从 BOOTH 下载的 `PDFReader-1.0.0.zip`。其中包含 unitypackage、README.txt、使用说明（Guides）和使用条款（Terms）。
2. 用 VCC 创建世界项目（也可以使用已有的项目）。
3. 导入 `PDFReader-1.0.0.unitypackage`。文件会放在 `Assets/PDFReader` 中。
4. 首次加载时，如果项目中没有 TextMesh Pro 的 Essential Resources，会自动导入。
5. 在 Unity 菜单中打开 **Tools > PDF Reader**。

可以用附带的 Demo PDF（`Assets/PDFReader/PDF/PDFReader-Original-Demo.pdf`）确认运行效果。下一步请看 [添加 PDF](add-pdf.html)。
