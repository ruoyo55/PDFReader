# PDFReader 使用说明

PDFReader 是在 VRChat 世界中阅读 PDF 的阅读器。在 Unity 中烘焙 PDF（转换为显示用的数据）并加入世界后，PC 上用鼠标、VR 中用手柄射线阅读。

体验世界：<https://vrchat.com/home/world/wrld_0b77585b-65bf-45e9-ac2b-e50005117117>

## 使用环境

- VRChat PC 版世界（PC 桌面 / PC VR）。不支持 Android（Quest 一体机等）和 iOS
- Unity 2022.3.22f1
- 已在 VRChat SDK - Worlds 3.9.0 上确认运行（使用 VCC 创建的世界项目）
- 烘焙 PDF 需要 Windows（x64）

每个世界放一台阅读器。多份 PDF 在书库中切换。

无法在 VRChat 内从本地文件或 URL 打开新的 PDF。请预先在 Unity 中烘焙 PDF 并加入世界。
