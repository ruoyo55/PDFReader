# 월드에서 조작하기

PC 데스크톱에서는 마우스로, VR에서는 컨트롤러 레이저로 조작합니다. 리더를 손에 들고 원하는 각도로 읽을 수 있습니다.

## 홈

![홈 화면](../assets/images/en-home.png)

**라이브러리 열기**로 PDF 목록을 엽니다. 이전에 읽던 곳이 있으면 오른쪽 위의 빨간 책갈피로 이어 읽을 수 있습니다.

## 라이브러리

![라이브러리](../assets/images/en-library.png)

읽고 싶은 PDF를 고르세요. 오른쪽 위의 돋보기로 제목을 검색할 수 있습니다.

## 읽기 화면

![읽기 화면](../assets/images/en-reading.png)

- 페이지의 왼쪽이나 오른쪽 가장자리를 클릭하면 페이지를 넘깁니다. 길게 누르면 계속 넘깁니다.
- 확대한 상태에서는 페이지 중앙을 드래그하여 보이는 위치를 옮길 수 있습니다.
- VR에서는 본문을 가리키고 오른쪽 스틱으로 확대·축소합니다.
- PC에서 리더를 들고 있을 때는 Q / E 키로도 페이지를 넘길 수 있습니다.
- 왼쪽 아래는 목차, 오른쪽 아래는 설정, 오른쪽 위는 뒤로 버튼입니다.

## 목차

![목차](../assets/images/en-contents.png)

장을 선택하면 해당 페이지로 이동합니다. 원본 PDF에 목차 데이터가 있을 때 사용할 수 있습니다.

## 설정

설정에는 보기, 화면, 기기의 세 탭이 있습니다.

![설정: 보기](../assets/images/en-settings-view.png)

**보기**: 확대 비율, 너비 맞춤 / 페이지 맞춤, 페이지 번호를 입력해 이동(PDF를 열었을 때만)

![설정: 화면](../assets/images/en-settings-display.png)

**화면**: 라이트 / 다크, 야간 이미지 반전, 페이지 배치(자동, 한 페이지, 두 페이지)

![설정: 기기](../assets/images/en-settings-device.png)

**기기**: 리더 크기, 밝기, 인터페이스 언어(English, 日本語, 简体中文, 한국어). 인터페이스 언어를 고르지 않으면 VRChat의 언어 설정에 맞춰 자동으로 선택됩니다. 번역되는 것은 조작 화면뿐이며, PDF 내용은 그대로 표시됩니다.

## 동기화

표시 중인 PDF, 페이지, 화면, 확대 비율, 보이는 위치, 라이트 / 다크, 밝기, 리더 크기는 같은 인스턴스의 모든 플레이어에게 동기화됩니다. 인터페이스 언어와 읽기 위치 기록은 플레이어마다 따로 저장됩니다.
