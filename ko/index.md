# PDFReader 설명서

PDFReader는 VRChat 월드에서 PDF를 읽기 위한 리더입니다. Unity에서 PDF를 베이크(표시용 데이터로 변환)하여 월드에 넣고, PC에서는 마우스로, VR에서는 컨트롤러 레이저로 읽습니다.

체험 월드: <https://vrchat.com/home/world/wrld_0b77585b-65bf-45e9-ac2b-e50005117117>

## 동작 환경

- VRChat PC 월드(PC 데스크톱 / PC VR). Android(Quest 단독 실행 등)와 iOS는 지원하지 않습니다
- Unity 2022.3.22f1
- VRChat SDK - Worlds 3.9.0에서 동작 확인(VCC로 만든 월드 프로젝트)
- PDF 베이크에는 Windows(x64)가 필요합니다

리더는 월드당 한 대입니다. 여러 PDF는 라이브러리에서 전환합니다.

VRChat 안에서 로컬 파일이나 URL로 새 PDF를 열 수는 없습니다. PDF는 미리 Unity에서 베이크하여 월드에 넣어 주세요.
