# 설치

작업 전에 프로젝트를 백업하세요. 처음 사용할 때는 테스트용 프로젝트에서 먼저 사용해 보는 것을 권장합니다.

1. BOOTH에서 다운로드한 `PDFReader-1.0.0.zip`의 압축을 풉니다. unitypackage, README.txt, 설명서(Guides), 이용약관(Terms)이 들어 있습니다.
2. VCC로 월드 프로젝트를 만듭니다(기존 프로젝트를 사용해도 됩니다).
3. `PDFReader-1.0.0.unitypackage`를 임포트합니다. 파일은 `Assets/PDFReader`에 들어갑니다.
4. 처음 불러올 때 프로젝트에 TextMesh Pro의 Essential Resources가 없으면 자동으로 임포트됩니다.
5. Unity 메뉴에서 **Tools > PDF Reader**를 엽니다.

동작 확인에는 함께 제공되는 Demo PDF(`Assets/PDFReader/PDF/PDFReader-Original-Demo.pdf`)를 사용할 수 있습니다. 다음은 [PDF 추가하기](add-pdf.html)로 넘어가세요.
